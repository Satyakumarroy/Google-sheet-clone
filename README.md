 Google Sheets Clone

This project is a simple clone of Google Sheets using HTML, CSS, and JavaScript. It allows users to interact with a spreadsheet-like interface where they can input data, format text, and perform basic calculations using formulas.

 Features

- Spreadsheet Layout: A grid of cells, each representing a row and column.
- Toolbar: Provides options for text formatting (bold, italic, font size, font color).
- Formula Bar: Allows users to input formulas to calculate values based on other cells.
- Formulas Supported:
  - Basic math operations (SUM, AVERAGE, MAX, MIN).
  - Text functions (TRIM, UPPER, LOWER).
  - Custom function: `FIND_AND_REPLACE`.
  - Cell references (e.g., `A1`, `B2`).
- Editable Cells: Each cell is content editable, and users can input or update values directly.
- Dynamic Sheet Generation: A sheet with 20 rows and 26 columns is generated by default.

 Technologies Used

- HTML: Structure and layout of the page.
- CSS: Styling for the sheet and toolbar.
- JavaScript : Functionality for cell interactions, formula evaluation, and text formatting.

 Installation

1. Clone the repository to your local machine:
   ```bash
   git clone <repository-url>
   ```
   
2. Navigate to the project directory:
   ```bash
   cd <project-directory>
   ```

3. Open the `index.html` file in a web browser to use the Google Sheets Clone.

How to Use

1. Editing Cells: Click on a cell to select it and input or edit its value. Press `Enter` to finalize the input.
2. Formula Bar: You can input formulas directly in the formula bar at the top. Supported formulas include `SUM`, `AVERAGE`, `MAX`, `MIN`, `TRIM`, `UPPER`, `LOWER`, and custom `FIND_AND_REPLACE`.
3. Text Formatting: Use the toolbar at the top to format the selected text:
   - B: Bold text
   - I: Italicize text
   - Font Size: Adjust the font size of the selected text
   - Font Color: Change the color of the text
4. Formulas: Formulas start with an equal sign (`=`). For example:
   - `=SUM(A1:A3)` will sum the values in cells A1 to A3.
   - `=UPPER(A1)` will convert the value in A1 to uppercase.
   - `=FIND_AND_REPLACE(A1:A3, "oldText", "newText")` will find and replace text in a specified range.

Functions Explained

 `SUM(range)`
Calculates the sum of a range of cells.

`AVERAGE(range)`
Calculates the average value of a range of cells.

`MAX(range)`
Returns the maximum value from a range of cells.

 `MIN(range)`
Returns the minimum value from a range of cells.
 `TRIM(cell)`
Trims whitespace from the value in the specified cell.

 `UPPER(cell)`
Converts the value in the specified cell to uppercase.

`LOWER(cell)`
Converts the value in the specified cell to lowercase.

 `FIND_AND_REPLACE(range, findText, replaceText)`
Finds and replaces occurrences of `findText` with `replaceText` in the specified range of cells.
